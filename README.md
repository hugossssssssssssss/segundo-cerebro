## 🌟 O que é o Klaus?

O **Klaus** é uma aplicação web moderna e ultrarrápida criada para funcionar como uma extensão do seu cérebro. Ele conecta **anotações ricas, gestão ágil de tarefas, murais visuais, diagramas infinitos, CRM pessoal e plano de carreira** diretamente a um repositório privado seu no GitHub.

```
┌─────────────────────────────────────────────────────────────┐
│                   Navegador Web ou Android                  │
│   (Zero Servidor • Hidratação em 0ms • Offline First)       │
└──────────────┬───────────────────────────────┬──────────────┘
               │ GitHub API (Git Trees + GQL)  │ Google Gemini API
               ▼                               ▼
  ┌───────────────────────────┐   ┌───────────────────────────┐
  │  Seu Repositório Privado  │   │  Inteligência Artificial  │
  │  (segundo-cerebro-dados)  │   │  (Chat, OCR, Transcrição) │
  │  ├── notas/*.md           │   └───────────────────────────┘
  │  ├── tarefas/*.md         │
  │  ├── pdi/metas/*.md       │
  │  ├── pdi/entregas/*.md    │
  │  ├── referencias/*.md     │
  │  └── lousas/*.excalidraw  │
  └───────────────────────────┘
```

### 💎 Os 3 Princípios Fundamentais do Klaus:
1. **Soberania Absoluta dos Dados**: Seus arquivos `.md` são a única fonte da verdade. Não há banco de dados proprietário, lock-in nem conversões misteriosas. Seus dados continuam sendo arquivos de texto puro que você poderá abrir em qualquer editor hoje ou daqui a 30 anos.
2. **Custo R$ 0 Para Sempre**: Funciona inteiramente no navegador via GitHub Pages, GitHub API e camada gratuita do Google Gemini. Zero custos de infraestrutura ou mensalidades.
3. **Velocidade Extrema (0ms / Percepção Instantânea)**: Carregamento otimizado com cache local síncrono e validação em segundo plano (SWR). Perfeito para usar como **Nova Guia do Chrome**.

## 🚀 Funcionalidades & Módulos

### 🏠 1. Painel Principal Bento (Home Modular)
- **Grade Bento de 12 colunas 100% personalizável**: Arraste, redimensione, ative ou oculte widgets conforme sua rotina.
- **Widgets Disponíveis**:
  - 🎯 **Foco de Hoje**: Tarefas prioritárias do dia com marcação rápida e visual de urgência.
  - 📝 **Notas Recentes**: Acesso imediato às anotações recentes com abertura instantânea.
  - 🎨 **Mural de Referências**: Grade visual com pré-visualização de imagens e paletas de cores.
  - 🏆 **Metas & Carreira (PDI)**: Acompanhamento de progresso das suas metas ativas.
  - ⚡ **Scratchpad**: Bloco de anotações rápidas com salvamento instantâneo no cofre.
  - 🔍 **Busca Web Integrada**: Mecanismo com atalhos para Google, Bing e DuckDuckGo.
  - 🛠️ **Hub de Ferramentas**: Acesso rápido ao Conversor, Ferramentas PDF, Gravador de Voz e Sons.

---

### 📝 2. Notas & Editor Notion-like (Markdown Puro)
- **Editor de Blocos Moderno**: Títulos, listas, checklists, citações, tabelas, blocos de código com syntax highlighting e divisores.
- **Conexões Bidirecionais (`@menções`)**: Conecte ideias digitando `@` no meio do texto para linkar notas, tarefas, pessoas ou referências.
- **Recursos Avançados**:
  - 📑 Sumário automático (TOC) com navegação fluida por cabeçalhos.
  - 🔄 Refatoração inteligente de links: ao renomear uma nota, todos os links do cofre são atualizados com segurança.
  - 📜 Histórico de Versões com Diff Visual do Git.
  - ⭐ Barra de Favoritos no topo para acesso em 1 clique.
  - 🖨️ Exportação instantânea para PDF, Markdown ou cópia limpa.

---

### ✅ 3. Gestão de Tarefas & Produtividade
- **Visões Flexíveis**: Alterne entre visão de **Quadro Kanban**, **Calendário Mensal** ou **Lista**.
- **Matriz de Urgência & Prazos**: Cálculo visual inteligente de tarefas (Atrasadas, Hoje, Próximas, Sem Prazo).
- **Subtarefas Interativas**: Caixas de seleção diretamente no corpo do `.md` com cálculo de barra de progresso.
- **Cronômetro Pomodoro Integrado**: Timer de foco com ciclos personalizáveis que registra as sessões de trabalho diretamente na nota da tarefa.
- **Filtros Avançados & Seleção em Lote**: Filtre por tags, prioridade ou urgência e mova/conclua múltiplos itens na `BarraAcoesLote`.

---

### 🎯 4. Plano de Carreira & PDI (Plano de Desenvolvimento Individual)
- **Metas & Entregas Vinculadas**: Defina metas estratégicas de carreira e desdobre em entregas concretas.
- **Dossiê de Carreira & Brag Document**: Gere dossiês executivos automáticos das suas realizações, impactos e entregas com apoio da IA.
- **Indicadores de Progresso**: Barras de completude calculadas a partir das entregas realizadas.

---

### 🎨 5. Referências Visuais & Moodboards
- **Galeria Visual de Inspiração**: Upload e visualização de imagens diretamente no repositório de dados.
- **Contexto Criativo**: Registre o campo *"Por que salvei?"*, adicione tags temáticas e links originais de inspiração.
- **Visualizador em Modal**: Zoom, visualização em tela cheia e paletas de cores.

---

### 🖌️ 6. Lousas Infinitas (Excalidraw & Diagramas)
- **Lousa de Desenho Livre**: Desenhe wireframes, diagramas arquiteturais, fluxogramas e esboços com **Excalidraw** embutido.
- **Salvamento Nativo**: Arquivos guardados com extensão `.excalidraw` no cofre.
- **Suporte a Mermaid e Grafos**: Crie diagramas técnicos a partir de texto puro.

---

### 🧠 7. Grafo Neural (Rede de Conhecimento)
- **Teia de Conexões em Tempo Real**: Visualize como suas notas, ideias, tarefas e contatos se conectam.
- **Física Interativa**: Navegação com zoom, física de forças, filtro por categorias e localização de notas órfãs.

---

### 👥 8. Árvore de Contatos (CRM Pessoal & Profissional)
- **Estrutura Hierárquica**: Organize contatos por Empresa, Projeto, Círculo ou Especialidade.
- **Ficha Completa**: Cargo, e-mail, telefone, redes sociais, histórico de conversas e notas vinculadas.

---

### 🤖 9. Assistente IA & Chat com o Cofre (Google Gemini)
- **Conversas Contextualizadas**: A IA lê seus arquivos para responder dúvidas cruzadas, sintetizar ideias e propor soluções.
- **Criação e Edição por Linguagem Natural**: Peça para a IA redigir uma nota ou criar tarefas (com confirmação explícita antes de gravar).
- **IA Ética e Transparente**: Toda sugestão ou documento preenchido por IA recebe a marcação `ia_sugeriu: true` no frontmatter até sua conferência.

---

### 🎙️ 10. Transcritor de Áudio Local (Whisper AI)
- **Privacidade Total**: Transcreva notas de voz e gravações 100% no navegador (WebAssembly/ONNX) sem enviar seu áudio para a nuvem.
- **Resumo Automático**: Formatação estruturada em tópicos com identificação de tarefas a realizar.

---

### 🧰 11. Canivete Suíço de Utilitários
- **📄 Ferramentas PDF**: Unir, dividir, comprimir e extrair texto com OCR local.
- **🔄 Conversor Universal**: Converta imagens (PNG, JPG, WebP, SVG), Markdown, JSON e textos formatados.
- **📚 Pesquisa de Livros**: Catálogo e agregador de referências bibliográficas para leitura e estudos.
- **🎧 Sons de Foco**: Player integrado com sons ambientes (chuva, cafeteria, ruído branco, ondas alfa/binaurais).
- **🎮 Jogos de Foco & Pausa**: Termo (Wordle) e Cruzadinhas diárias para descompressão criativa.
- **💻 Testador de Hardware**: Diagnóstico rápido de câmera, microfone, display, áudio e teclado.

---

### 🧩 12. Extensão Web Clipper & Captura Rápida
- **Extensão para Google Chrome**: Capture artigos completos, resumos de páginas e links direto para o cofre com 1 clique.
- **Captura Rápida (`⌘J`)**: Modal global acessível de qualquer lugar para descarregar pensamentos instantaneamente.

---

### 🔔 13. Notificações & Agendador Autônomo
- **Alertas no Telegram**: Receba avisos de tarefas atrasadas ou lembretes diários no celular via Telegram Bot.
- **Agendador Gratuito (GitHub Actions)**: Rotina cron instalável em 1 clique que roda no seu repositório de dados, disparando alertas mesmo com o computador desligado.

## 🏁 Como Começar em 3 Minutos

1. Abra o Klaus: **https://hugossssssssssssss.github.io/segundo-cerebro/**
2. Na primeira visita, o **Passo a Passo de Boas-Vindas** conduzirá a configuração:
   - **Crie um repositório privado** no GitHub (ex: `segundo-cerebro-dados`).
   - **Gere um token Fine-Grained PAT** com permissão `Contents: Read and write` apenas para esse repositório.
   - Cole as credenciais e clique em **Salvar e Testar Conexão**.
3. **Pronto!** Seu segundo cérebro já está conectado e pronto para uso.

> 💡 **Dica no Celular (Android / iOS):** Abra o link no navegador e toque em **"Adicionar à tela inicial"** para instalar o Klaus como um Progressive Web App (PWA) nativo com ícone próprio e sem barras de navegação.

## 🛡️ Privacidade, Segurança & Sem Servidor

- **Seus dados nunca passam por servidores intermediários**: O navegador conversa diretamente com a API do GitHub (`api.github.com`) através de conexões HTTPS criptografadas.
- **Armazenamento 100% Local**: O token do GitHub e a chave do Gemini ficam guardados exclusivamente no `localStorage` do seu navegador.
- **Sem Banco de Dados Proprietário**: Se você quiser exportar tudo, basta clonar o repositório pelo Git ou baixar um `.zip` na aba de Configurações.

## 💻 Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/hugossssssssssssss/segundo-cerebro.git

# 2. Acesse a pasta do projeto
cd segundo-cerebro

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev

# 5. Execute a suíte de testes
npm test

# 6. Gere o build de produção
npm run build
```
